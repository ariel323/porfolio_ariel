### Glassmorphism

```css

backdrop-filter: blur(20px);
border: 1px solid rgba(100, 255, 218, 0.2);
```

### Gradientes Animados

```css

    box-shadow: 0 0 20px rgba(100, 255, 218, 0.2);

    box-shadow: 0 0 40px rgba(100, 255, 218, 0.4);

}
```
